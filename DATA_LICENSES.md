# Data and Model Licenses

The application source is MIT-licensed. Dictionary data and neural models are
separate works and retain their respective notices.

## Included open-data inputs

- **Kaikki / Wiktionary extracts:** distributed under the licenses stated by
  Wiktionary, including CC BY-SA and GFDL terms. The release database records
  the source category and preserves the corresponding attribution metadata.
- **FreeDict English/Turkish and Turkish/English data:** GPL-2.0-or-later as
  stated in the source TEI headers. The complete corresponding license text and
  source attribution must remain with redistributed database artifacts.
- **Academic Word List machine-readable mirror:** CC0-1.0 for the mirror used
  by the build tooling. AWL provenance is retained in the release manifest.
- **CEFR-J / Octanove profiles:** used under their stated attribution and
  CC BY-SA 4.0 terms where applicable.
- **Opus-MT-derived local models:** CC BY 4.0 attribution applies to the
  bundled model assets. Model source/version and hashes are recorded in the
  release manifest.

## Removed restricted/proprietary inputs

TDK dictionary/definition data and the legacy Webster-derived table are not
part of the public release database. They must not be reintroduced without a
documented redistribution permission.

## Distribution rule

The full database is a separate data artifact. Do not describe the entire
archive as MIT-licensed. Redistributors must keep this file, the source
attribution, and the applicable license texts with the database/model files.
