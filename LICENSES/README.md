# Third-party license texts

These files are shipped with the Windows release so the corresponding notices
travel with the binary and data assets.

- `MIT-CustomTkinter.txt` — CustomTkinter 6.0.0
- `BSD-3-Clause-darkdetect.txt` — darkdetect 0.8.0
- `HPND-Pillow.txt` — Pillow 12.3.0
- `LGPL-3.0-pystray.txt` and `GPL-3.0-pystray.txt` — pystray 0.19.5
  (the LGPL text incorporates the GPL terms)
- `MIT-CTranslate2.txt` — CTranslate2
- `Apache-2.0.txt` — SentencePiece and other Apache-2.0 components
- `GPL-2.0-FreeDict.txt` — FreeDict data/source terms
- `CC0-1.0.txt` — CC0 dedication used by the AWL mirror
- `CC-BY-4.0.txt` — CC BY 4.0 attribution terms used by model/data sources
- `CC-BY-SA-3.0.txt` and `CC-BY-SA-4.0.txt` — CC BY-SA terms used by
  Wiktionary/Kaikki and applicable data extracts
- `GFDL-1.3.txt` — GNU Free Documentation License terms where the source
  dataset carries GFDL attribution

The project `LICENSE` at the repository root covers LocalDictionary's own
source code only. `DATA_LICENSES.md` identifies which data/model terms apply
to the release assets; consult the original source headers and attribution
records when redistributing a modified database.
