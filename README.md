# LocalDictionary

LocalDictionary is a Turkish–English dictionary and translation project.

## Download

Portable Windows app, no installation needed. Unzip it and run `localdictionary.exe`.

- **[Download LocalDictionary](https://github.com/erdemkoc1/localdictionary/releases/download/v1.42-beta.1/LocalDictionary-v1.42.0-beta.1-win64.zip)**: Portable Windows app, 357 MB (zip)
- **[Download SHA-256 checksum](https://github.com/erdemkoc1/localdictionary/releases/download/v1.42-beta.1/LocalDictionary-v1.42.0-beta.1-win64.zip.sha256)**: Verify the download before running it

**Beta:** sentence translation is still in beta and not ready yet. I'm continuing to work on it.

This beta build is not code-signed. Compare the zip's SHA-256 with the checksum file before running it. All releases are on the [Releases page](https://github.com/erdemkoc1/localdictionary/releases).

**Uninstall:** run `uninstall.exe` in the app folder. It removes the startup entry, context-menu entries, and Start Menu shortcut, plus the app files. Your user data is kept unless you choose to delete it.
